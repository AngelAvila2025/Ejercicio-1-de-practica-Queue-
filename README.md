Instrucciones:
1. Crea una clase Customer con id y name.
2. Crea una ArrayQueue<Customer> y agrega varios clientes (5–6).
3. Imprime la Queue
4. Crea un método reverse() que invierta el orden de la cola. (Puedes hacerlo con recursión o con un Stack<T> auxiliar. ) Puede devolver una nueva queue o puede invertir la actual
5. Imprime la Queue demostrando que tiene el mismo numero de elementos.

Entregables:
Url del repo (que lleva a la carpeta)
Capturas de pantalla
SALIDA ESPERADA

[Customer{id=1, name='Ana'}, Customer{id=2, name='Luis'}, Customer{id=3, name='Maya'}]
Después de invertir:
[Customer{id=3, name='Maya'}, Customer{id=2, name='Luis'}, Customer{id=1, name='Ana'}]
